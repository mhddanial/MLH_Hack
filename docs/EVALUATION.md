  - `pku_short_01` -> `defect_class: "missing_component"`, `location_hint: "lower-left quadrant, large rectangular SMT footprint"`, `latency: 66,664 ms`.
  - *Root Cause (DMAIC Analyze):* The PKU dataset consists of bare etched copper PCBs prior to SMT pick-and-place. Without an explicit rule distinguishing an unpopulated bare board from a populated PCBA missing a single part, the multimodal VLM flagged bare footprints as missing components.

  - Added explicit rule under `ALLOWED DEFECT CLASSES`: *"If the entire board is an unpopulated bare PCB with zero components mounted anywhere, do NOT report bare footprints as `missing_component`; instead inspect the copper traces for `solder_bridge` / copper shorts or `uncertain_or_other` trace anomalies."*

## 4. Honest Limitations & Scope Statement

1. **Sample-Set Scope:** These metrics are measured on the 16-image hackathon evaluation set (PKU Open Lab bare-PCB dataset + procedural SMT macro reference cards) and do **not** represent a factory-wide Gauge R&R or Six Sigma capability study.
2. **X-Ray Boundary:** Sub-surface solder defects (BGA/QFN voids, head-in-pillow, internal cracks) cannot be detected optically and require X-ray inspection (`AXI`).
3. **Human Verification Gate:** Regardless of model confidence, `operator_confirmation_required` is forced to `true` on 100% of records, and only a human inspector can commit a final `pass`, `rework`, `quarantine`, or `escalate` disposition.
